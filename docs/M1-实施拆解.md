## 关键实现说明（绩效复刻）
- 方案字段表达“留空”用 `空` 字面量，回写层对 `Value::Empty` 清空目标单元格（保留样式/坐标），对数值写 `<v>`。
- 姓名连接统一走 `normalize_key`（去空白/全角），对齐旧代码 `HandleStringSpace`（班主任表姓名带首尾空格）。
- 旧代码用 `ParseFloat(s,32)` 读 课时/天数/早读 → 方案列加 `bits:32`，读取时舍入到 f32 后参与 f64 计算，与 golden 数值精确一致。
- 三条 R3 语义已从引擎代码迁为方案可编辑项（默认值与旧行为一致）：
  - 请假扣款封顶 = `参数.请假扣款上限`（默认 100）；
  - 扣课时排除假别集合写在聚合 WHERE（`类型 != '婚' AND …`）；
  - 折扣“职位数≥2 取最后一个非零值”用嵌套 IF 表达；折扣率/开关均为参数。
- 记录级统计由 reader 的 `continue_record_on` 合并能力提供：请假表拆成“物理行视图(qingjia) +
  记录视图(qingjia_jl)”，扣课用记录视图的聚合，补课时等按替课老师的统计仍用物理视图。
